# Plans

Working plans live here, one file per piece of substantive work, written by construct-the-plan. Shape and frontmatter: AGENTS.md § Plans.

Plans are scaffolding, not documentation. When the work ships and nothing references the plan anymore, delete it.

Plans live under `docs/`, so the link checker reads them like any other page. A plan that deletes or moves files has to name the old paths in words ("the old commands folder"), not as backticked or bare paths, or the check fails the moment the deletion lands. The same goes for paths in another tool's repository.
